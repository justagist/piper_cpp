piper_cpp apt repository

Standalone (non-ROS) Debian packages for the AgileX Piper C++ SDK - Ubuntu 24.04 (noble), amd64.

Install

sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://justagist.github.io/piper_cpp/piper-cpp-archive-keyring.gpg \
  -o /etc/apt/keyrings/piper-cpp-archive-keyring.gpg

echo "deb [signed-by=/etc/apt/keyrings/piper-cpp-archive-keyring.gpg] https://justagist.github.io/piper_cpp noble main" \
  | sudo tee /etc/apt/sources.list.d/piper-cpp.list

sudo apt update
sudo apt install libpiper-cpp-dev   # headers + static lib + CMake config
sudo apt install piper-cpp-tools     # optional: command-line utilities

Packages

  • libpiper-cpp-dev - static library, headers, and CMake package config (find_package(piper_cpp)).
  • piper-cpp-tools - command-line demo and utility executables.

Source: github.com/justagist/piper_cpp
